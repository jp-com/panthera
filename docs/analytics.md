# Marketing analytics
The storefront implements optional Meta browser events PageView, ViewContent, AddToCart and InitiateCheckout. It does not load Meta scripts until explicit marketing opt-in; Global Privacy Control disables marketing. The config endpoint enables tracking only in production with MARKETING_TRACKING_ENABLED=true and a valid META_PIXEL_ID. No account ID is configured, no external data was sent. No advanced matching, customer email, addresses or payment details are deliberately passed. Verify Meta automatic event settings and privacy disclosures before enabling. Meta SDK may independently collect network/browser metadata after consent. The simple preference UI requires legal/privacy review and cross-browser testing before launch.

Purchase events are intentionally NOT triggered on the thank-you page, because it does not verify payment. First-party paid order reporting comes from Neon and signed Stripe webhooks; refund synchronization remains a prerequisite for accurate net reporting. Server-side Meta Conversions API requires verified payment, stored applicable consent, correct event ID/deduplication and a restricted token, plus delivery/reconciliation tests. No purchase attribution or conversion rate is claimed until implemented and validated. GA4, Vercel Web Analytics and other providers are not connected.

References: https://developers.facebook.com/docs/meta-pixel/get-started/ and https://developers.facebook.com/docs/facebook-business-extension/fbe/guides/pixel-events . Verify in Meta Events Manager once the approved pixel is configured.
