# Initial admin dashboard
Open /admin.html after configuring ADMIN_ACCESS_TOKEN in Vercel as a sensitive server-only variable. Generate 32 random bytes locally (for example openssl rand -hex 32) and store the value in your password manager; never commit or send it in chat. The variable must be exactly 64 hexadecimal characters. Configure separately for preview and production. Without it the endpoint returns 401 and reveals no database data. The UI contains no credentials and the token is held only in memory, not local storage or a URL.
This first release is read-only and excludes customer email/address. It shows actual database totals, inventory, latest 50 orders and shipping rates. Net collected is gross paid amounts less recorded refunds, not profit or an accounting statement. Refund synchronisation, editing, fulfilment actions, managed staff identity, MFA and rate limiting remain launch gates. Prefer existing Neon Auth or another managed identity provider for multi-user operation.
