# Admin management
After applying db/002_admin_audit.sql, configure ADMIN_ACCESS_TOKEN and ADMIN_ORIGIN as server-side Vercel variables, then explicitly set ADMIN_WRITE_ENABLED=true for the chosen environment. Keep writes disabled until independent database roles, auth and database integration tests are reviewed. The interface does not enable checkout, issue refunds, change payment status or release reservations manually. All changes use authenticated same-origin POST requests and are audited in the transaction. Shipping prices are USD cents per unit; stock is physical units on hand, including reserved units. Fulfilment transitions are paid only: unfulfilled -> processing -> shipped -> delivered. Dispatch enqueues an email notification, but no email is sent until an outbox worker is configured. Use separate tokens and DB branches for preview/production. No personal information is returned by the summary API. Single-operator high-entropy token is interim; managed staff auth, MFA, rate limiting, and roles are required before multi-user launch.
